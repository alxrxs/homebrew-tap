# alxrxs/tap

Homebrew formulae for my open-source macOS apps. They build from source on your Mac, so you
need Xcode or the Command Line Tools (`xcode-select --install`).

```sh
brew install alxrxs/tap/<name>
```

| Formula | App |
| --- | --- |
| `flipane` | [Flipane](https://github.com/alxrxs/flipane): ⌘Tab that switches windows, not apps |
| `louder` | [Louder](https://github.com/alxrxs/louder): turn your Mac up past 100%, for every app or just some |
